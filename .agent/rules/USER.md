# User Preferences (USER.md)

- **Language:** German for all user communications; English for code, comments, plans, and technical documentation.
- **Door Locking:** Separate key `[L]` to lock / unlock doors and watertight bulkheads; `[E]` exclusively to open / close unlocked doors.
- **Explosion Tuning:** Realistic contact pressure: TNT only breaches hull/bulkheads in direct proximity; explosions on upper decks/bridge must not cause keel breaches.
- **Flooding Behavior:** Dynamic hydrostatic multi-deck spillover: full holds overflow through stairwells and open doors onto the main deck.
- **Quality & Thoroughness:** No mockups or dummy placeholders; all physics, visual meshes, and interactions must be fully functional.
